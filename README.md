# pdi164106
Repositório utilizado como exemplo para os(as) estudantes da unidade curricular Processamento Digital de Imagens: Uma Abordagem Prática.

## Instalação
* Criação do ambiente virtual (exemplo omeado como '.venv')
`python -m venv .venv`

* Ative o ambiente virtual (abra um novo terminal)

* Instação das dependências
`python -m pip install -r requirements.txt`
