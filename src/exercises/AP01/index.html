📋 INSTRUÇÕES PARA A ATIVIDADE PRÁTICA

Siga o roteiro abaixo para validar as configurações do seu ambiente de desenvolvimento e realizar a entrega da atividade no repositório do GitHub.

⚙️ Roteiro de execução
  1. Abra o VS Code e sincronize o seu repositório da unidade curricular.
  2. Dentro do repositório da disciplina, crie uma nova pasta exclusivamente para esta atividade prática (ex.: APxx).
  3. Crie o arquivo de script (ex.: main.py) com o código abaixo: 
    import os
import os
import sys
import logging
from pathlib import Path
import datetime

def setup_logger():
    script_dir = Path(__file__).resolve().parent
    log_dir = script_dir / "log"
    if not log_dir.exists():
        log_dir.mkdir(parents=True)
    timestamp = datetime.datetime.now().strftime("%Y%m%d_%H%M%S")
    log_file = log_dir / f"environment_verification_{timestamp}.log"
    logger = logging.getLogger("VerificadorAmbiente")
    logger.setLevel(logging.INFO)
    if not logger.handlers:
        file_handler = logging.FileHandler(log_file, encoding='utf-8')
        file_handler.setLevel(logging.INFO)
        console_handler = logging.StreamHandler()
        console_handler.setLevel(logging.INFO)
        formatter = logging.Formatter('%(asctime)s - %(levelname)s - %(message)s', datefmt='%Y-%m-%d %H:%M:%S')
        file_handler.setFormatter(formatter)
        console_handler.setFormatter(formatter)
        logger.addHandler(file_handler)
        logger.addHandler(console_handler)
    return logger, log_file

def check_environment(logger):
    logger.info("--- Iniciando verificação do ambiente ---")
    current_dir = os.getcwd()
    logger.info(f"Diretório atual de trabalho (CWD): {current_dir}")
    python_executable = sys.executable
    logger.info(f"Caminho do executável Python: {python_executable}")
    in_venv = sys.prefix != sys.base_prefix
    logger.info(f"Executando dentro de um Virtual Environment (venv): {'Sim' if in_venv else 'Não'}")
    if in_venv:
         logger.info(f"Caminho do Virtual Environment: {sys.prefix}")
    logger.info("--- Fim da verificação do ambiente ---")

def check_library_versions(logger):
    logger.info("--- Iniciando verificação de bibliotecas ---")
    try:
        import cv2
        import numpy
        import matplotlib
        logger.info(f"Versão do NumPy: {numpy.__version__}")
        logger.info(f"Versão do Matplotlib: {matplotlib.__version__}")
        logger.info(f"Versão do OpenCV: {cv2.__version__}")
    except ImportError as e:
        logger.error(f"Erro ao importar bibliotecas necessárias: {e}")
        logger.error("Certifique-se de instalá-las usando 'pip install opencv-python numpy matplotlib'")
        sys.exit(1)
    logger.info("--- Fim da verificação de bibliotecas ---")

if __name__ == "__main__":
    logger, log_file_path = setup_logger()
    logger.info(f"Log iniciado no arquivo: {log_file_path}")
    check_environment(logger)
    check_library_versions(logger)
    logger.info("Processo concluído com sucesso.")
  4. Execute o script disponibilizado pelo professor (ex.: main.py).
  5. Caso o script tenha sido executado com sucesso, um arquivo de log deverá ser gerado.
  6. Envie o código para o GitHub por meio das ações de commit e push.
📌 Como saber se o procedimento foi bem-sucedido?
Acesse a página do seu repositório no GitHub pelo navegador e verifique se a nova pasta e o arquivo do script estão visíveis. Se ambos estiverem disponíveis, sua atividade terá sido entregue com sucesso!
