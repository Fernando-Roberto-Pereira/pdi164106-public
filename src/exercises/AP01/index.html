💻 REPOSITÓRIO DE ATIVIDADES NO GITHUB

Para esta unidade curricular, você deverá criar um repositório privado no GitHub. É nele que você enviará e atualizará todas as suas atividades avaliadas ao longo do semestre.

📦 Como criar um repositório privado no GitHub

Para organizar suas entregas, você precisará criar um repositório privado em sua conta do GitHub. Para isso, siga os passos abaixo:

  1. Acesse o GitHub e faça login em sua conta.
  2. No canto superior direito, clique no ícone de mais (+) e selecione Novo repositório / New repository.
  3. Configure as opções da página conforme orientado:
    • Nome do repositório / Repository name: Digite um nome para o repositório (ex: meu-repositorio ou uc-pdi).
    • Visibilidade / Visibility: Marque obrigatoriamente a opção Privado / Private.
    • Inicialização / Initialize: Marque a opção Adicionar um arquivo README / Add a README file.
  4. Clique no botão Criar repositório / Create repository ao final da página.
🔗 Como obter o link (URL) do seu repositório

Para que o professor tenha acesso ao repositório privado criado, é necessário informar o seu endereço web (URL). Para isso, siga os passos abaixo:

  1. No GitHub, navegue até a página inicial do seu repositório privado.
  2. Clique na aba Código / Code (canto superior esquerdo).
  3. Clique no botão verde Código / Code e copie a URL no formato HTTPS (ex: https://github.com/seu-usuario/meu-repositorio.git).
🔑 Como criar um Token de Acesso Pessoal (Fine-grained token)

Para permitir que o professor tenha acesso seguro ao repositório privado, será necessário gerar um Token de Acesso Pessoal (Fine-grained token) no GitHub. Para isso, siga os passos abaixo:

  1. No GitHub, clique na sua foto de perfil (canto superior direito) e acesse Configurações / Settings > Configurações do desenvolvedor / Developer settings > Tokens de acesso pessoal / Personal access tokens > Tokens refinados / Fine-grained tokens.
  2. Clique no botão Gerar novo token / Generate new token.
  3. Configure os campos obrigatórios conforme as orientações abaixo:
    • Nome do token / Token name: Digite um nome identificador (ex: Token-UC-IFSC).
    • Descrição / Description: Descreva a finalidade (ex: Token para envio das atividades da UC no IFSC).
    • Expiração / Expiration: Selecione o prazo desejado (ex: Defina uma data final até o fim do semestre).
    • Acesso ao repositório / Repository access: Marque a opção Somente repositórios selecionados / Only select repositories e selecione o repositório privado específico da disciplina.
    • Permissões / Permissions: Expanda a seção Permissões do repositório / Repository permissions, localize a permissão Conteúdos / Contents e altere para Leitura e escrita / Read and write (permitindo ler e enviar código/arquivos).
  4. Clique em Gerar token / Generate token no final da página e copie o token gerado imediatamente, pois ele não será exibido novamente!
📌 Atenção: Este token será utilizado exclusivamente pelo professor para acessar, acompanhar e avaliar as atividades desenvolvidas. Você não precisará deste token para acessar o seu próprio repositório.
📂 Estrutura de pastas recomendada

Crie uma pasta dedicada para cada Atividade Prática (AP) (ex: AP01, AP02) e, quando a entrega exigir arquivos de mídia, utilize uma subpasta img/ para organizar suas imagens:

meu-repositorio/
├── AP01/
│   ├── img/
│   │   └── img01.png
│   └── main.py
├── AP02/
│   ├── img/
│   │   ├── img01.png
│   │   └── img02.png
│   └── main.py
├── APxx/
└── README.md

🕒 ATENÇÃO AO PRAZO DE ENVIO!

A entrega das atividades avaliativas é confirmada exclusivamente pelo envio (git push) ao servidor do GitHub.

📌 Atenção: Não basta fazer o commit no seu computador; os arquivos devem estar disponíveis no GitHub até a data e o horário limites. Alterações recebidas pelo servidor após o prazo não serão consideradas para a avaliação. Faça o push com antecedência!
