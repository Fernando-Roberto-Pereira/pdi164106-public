🖼️ otimização e destaque de RoI

No processamento digital de imagens, isolar e destacar uma Região de Interesse (RoI) permite a análise detalhada de elementos específicos de uma cena, sem a necessidade de processar a totalidade dos dados da imagem.

📸 Captura da imagem

Antes de iniciar a programação, obtenha uma imagem digital autoral utilizando a câmera do seu aparelho celular, uma câmera digital ou outro dispositivo de captura de sua preferência. A foto deve ter pelo menos um objeto de interesse.

🎯 Objetivo

Desenvolva um algoritmo em Python para executar os seguintes passos:

  1. Carregue a imagem colorida utilizando a biblioteca OpenCV.
  2. Crie uma imagem com as mesmas dimensões da imagem original e desenhe um objeto branco, utilizando formas geométricas (círculos, quadrados e elipses), que cubra o objeto de interesse da cena.
  3. Gere uma imagem a partir da imagem original que suprima o objeto de interesse.
  4. Gere uma imagem a partir da imagem original que contenha somente o objeto de interesse.
Apresentação dos resultados

Utilize a biblioteca Matplotlib para construir uma figura disposta em uma única linha com quatro subgráficos posicionados lado a lado:

  1. Exiba a imagem original.
  2. Exiba a imagem com a Região de Interesse (ROI).
  3. Exiba a imagem original sem o objeto de interesse.
  4. Exiba somente o objeto de interesse.
📌 Atenção: Adicione títulos identificadores a cada subgráfico e aplique os ajustes de espaçamento necessários para evitar a sobreposição de eixos e textos na figura final.
